# H3 Remote Workbench

GitHub 托管网页，本机 RTX 5090 D v2 运行 H3 720p或1080p / 14步工作流。网页不预览输入图片或生成视频，本机独立看板只显示队列和运行状态。

网页：[H3 工作台](https://ouyangqianshan1988-lgtm.github.io/h3-remote-workbench/)。测试版使用临时 HTTPS 隧道；工作站和隧道需要保持运行，隧道重新启动后需更新 config.js 中的地址。

## 模型选择

支持原版 H3 和 [DaSiWa H3 Hybrid V2](https://civitai.com/models/2877206?modelVersionId=3314675)。服务端仅接受固定模型白名单；未安装的模型无法提交。两者使用完全相同的 12+2 分步采样图，仅替换扩散模型。14步是沿用当前速度配置，作者对非蒸馏 V2 推荐20至25步，画质需要实测。

DaSiWa 官方 INT8 文件：`DasiwaMinimaxH3_dasiwaHybridV2_3203130.safetensors`；SHA256：`4CB8E1EAA9C3E5C664822760890BCBE6078455401CFA43205BAF322E856D25F8`。需放入 ComfyUI/models/diffusion_models，保留原文件元数据及上游许可。模型权重不在本仓库内。

## 本机启动

本项目目录应放在 ComfyUI 迁移包根目录下，名为 `web_portal`。运行包根目录的 `Start_H3_Web.bat`。需包内已有 Python、ComfyUI、TimelineDirector 插件及五项模型。

- `127.0.0.1:8190`：带登录的网页与受保护任务 API。
- `127.0.0.1:8191`：仅本机使用的独立 ComfyUI 工作进程，不得公开或建立隧道。
- `127.0.0.1:8192`：本机状态看板，不展示素材、提示词、用户名或结果。
- 模型路径和原有 ComfyUI 输入输出目录不变；远程任务仅使用本项目私有临时目录。
- 不要同时在原 ComfyUI 中运行 GPU 任务。

## 账号

账号保存在本机 `private/users.json`，使用随机盐和 scrypt 密码摘要。账号记录、密码、会话、上传素材、生成文件均不应提交 GitHub。仓库不包含可用账号；本机测试账号由管理员单独创建。

## 下载与清理

- 用户只能访问自己创建的任务；服务端固定工作流，不接受任意 ComfyUI 图或文件路径。
- 每账号同时一个未处理完的任务；单GPU顺序执行。参考图片可选，最多4张；不上传图片时按文字描述生成，720p最长约30秒，1080p最长约15秒。
- 点击“获取下载链接”，再点击“下载视频 / 右键另存为”。由浏览器下载管理器显示进度，文件支持 Range 请求和断点续传。
- 下载链接有效期一小时，失效可重新获取；链接到期不会删除视频。链接包含该文件的临时访问凭证，请勿转发。
- 下载或断网都不会自动清理；确认视频完整可播放后，点击“确认已保存，完成任务”。主账号结果删除，附账号永久归档保留。
- 未领取结果不再按一小时自动删除。服务重启仍会清理主账号临时文件，重启前请先保存结果。
- 关闭媒体元数据、采样预览和独立进程的控制台输出；任务结束即清除ComfyUI历史和中间节点缓存；数据库在内存中。
- 使用文件系统删除，不是安全擦除；系统页面文件、文件系统恢复、管理员访问不在应用层保密保证内。

## 公网部署

1. GitHub Pages只能提供静态网页；部署 `web/` 内容，或使用发布目录生成的独立 `index.html`。
2. 在 `web/config.js` 的 `PORTAL_API` 中设置受保护网关的HTTPS地址。不能填远程用户电脑上的127.0.0.1。
3. 本机以 `PORTAL_ORIGINS=https://账号.github.io` 环境变量启动，精确允许网页来源。
4. 通过HTTPS反向代理或隧道仅转发网关8190端口；不暴露8188、8191、8192。不要代理额外的ComfyUI路由。
5. GitHub仓库和Pages可见性必须由所有者确认。临时隧道仅用于测试，地址可能变更；长期使用应配置固定域名。

## 验证

2026-09-25 本机实测：登录、错误密码拒绝、未登录拒绝、私有文件禁止访问、图片上传、22帧视频生成与逐帧解码、伪造下载确认拒绝、下载完成确认、输入输出目录删除、ComfyUI历史清除、本机看板无媒体均通过。端到端测试约55秒，不代表所有素材的速度。

公网部署状态以管理员交付的地址为准；仅打开本地网页不代表已经部署到GitHub或可以从外网访问。

参考：[GitHub Pages说明](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)。

## 附账号与归档

附账号生成的 MP4 在完成时保存到 `E:\归档\账号名\年月日时分\年月日时分.mp4`；归档成功后立即清理临时输入输出，下载直接读取归档视频。原 test 账号不归档。后续账号默认归档，可在本机私有账号记录中配置 archive 字段。归档盘不可用时不接收附账号任务；生成后归档中断的结果保留并重试。

所有账号共用单 GPU 队列，按服务端接收请求顺序执行，后收到的小文件不能越过先收到的大文件；相同内容也分别生成，不跨账号共享结果。最多32个接收中或排队任务，每账号同时一个未处理任务。长视频使用单段直接生成，不做时间切段或拼接；保留原两阶段采样，时长受模型帧数对齐影响。

附属账号只允许原版 H3，网页不显示 DaSiWa 选项，接口也强制限制。主账号 test 保留模型切换。选择1080p时最长15秒，超过时长的请求由服务端拒绝。横屏1080p为1920×1080，竖屏为1080×1920。

归档以北京时间的生成完成时间命名（例如202609272044），同分钟冲突加序号。每个任务文件夹包含同名MP4、同名UTF-8提示词TXT，以及picture1.png等参考图（无图任务不含参考图）。

网页提供“H3二采”（原有12+2两阶段）与“原版H3”（14步全分辨率单阶段，关闭secondPass），两者使用同一原版INT8权重。附账号可选择这两种H3流程，主账号另保留DaSiWa。

所有账号可选择“H3画质优先”：原版INT8权重、20步全分辨率单阶段、参考图max、H.264 CRF18；网页选择时默认768p（1344×768或768×1344，比例7:4），仍可手动选择720p或1080p。1080p上限15秒，其余30秒。固定种子约1秒测试仅验证短片细节与完整流程，不保证长镜头效果。
